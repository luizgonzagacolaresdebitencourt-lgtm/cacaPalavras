# Product Requirements Document: CacaPalavras

## Visão Geral
Jogo casual de adivinhação de palavras estilo Wordle, disponível como aplicativo mobile (iOS/Android) com suporte a Português e Inglês.

## Funcionalidades Principais

### Mecânica de Jogo
- **Formato Wordle**: Palavra de 5 letras, 6 tentativas
- **Feedback visual**: Cores tradicionais (verde = posição certa, amarelo = letra certa posição errada, cinza = letra errada)
- **Modo Diário**: Uma palavra por dia, mesma para todos os jogadores
- **Categorias fixas**: Níveis Fácil/Médio/Difícil com listas de palavras específicas

### Sistema de Palavras
- Lista pré-definida de palavras embutida no aplicativo
- Suporte a categorias para definir dificuldade

### Interface e Experiência
- **Tema personalizável**: O jogador escolhe tema/cor
- **Idiomas**: Português e Inglês
- **Estatísticas completas**: Contador de jogos, taxa de acerto, sequência atual/máxima, média de tentativas

### Recursos Sociais
- **Compartilhamento de resultados**: Botão "Compartilhar" para copiar texto/resultados
- Foco single-player (estatísticas pessoais)

### Plataforma
- Aplicativo mobile nativo (iOS/Android)
- Web opcional como complemento

## Fluxo de Jogo
1. Jogador seleciona categoria (opcional) ou joga lista geral
2. Palavra do dia é sorteada/selecionada
3. Jogador tem 6 tentativas adivinhar a palavra
4. Após cada tentativa, feedback por cores é mostrado
5. Resultado é salvo nas estatísticas do jogador
6. Opção de compartilhar resultado nas redes sociais
